# TagLess

TagLess est une application Android pour scanner, comparer et sauvegarder des produits alimentaires.  

## Fonctionnalités
- Scanner des produits
- Ajouter à des listes de favoris
- Rechercher des aliments
- Localiser les magasins via Google Maps
- Gestion du compte utilisateur (connexion, création, modification, suppression)

## Dépendances
- Firebase Auth & Firestore
- Glide pour le chargement d’images
- RecyclerView
